# Superstore Sales Data Analysis (SQL & Power BI)

## 📌 Project Overview
This project presents an end-to-end data analysis pipeline using the Superstore sales dataset. The primary objective is to transform raw, unformatted transaction records into a clean, structured data model and extract actionable business insights regarding regional performance, product demand, and customer purchasing behavior. 

This repository currently features the **SQL Data Operations** phase, with a Power BI visualization dashboard in development.

## 🛠️ Tech Stack & Skills Demonstrated
- **Database / Environment:** SQLite, Visual Studio Code
- **Data Cleaning (ETL):** Standardized date formats (`YYYY-MM-DD`) using string manipulation (`SUBSTR`) and normalized column headers via SQL Views.
- **Advanced SQL Techniques:** 
  - Common Table Expressions (CTEs) for multi-step calculations.
  - Subqueries for dynamic baseline comparisons (e.g., filtering above-average sales).
  - Complex aggregations (`GROUP BY`, `ORDER BY`, `COUNT`, `SUM`).
  - Table aliasing for clean, readable code.

## 🔍 Key Business Questions Answered
1. **Customer Analytics:** Who are the top 10 customers by order volume, and which VIP clients generate sales strictly above the company average?
2. **Regional Revenue Contribution:** What is the exact percentage of total company income generated by each individual region?
3. **Product & Category Dynamics:** Which product categories drive the highest transaction volume vs. the highest total revenue across different geographic markets?
4. **Isolated Market Trends:** Who are the top 5 highest-spending customers exclusively within the West Region?

## 📁 Repository Structure
- `superstore_sql_analysis.sql` - The complete SQL script containing the data cleaning View, EDA queries, and business metric CTEs.
- `Store_Sales_Clean.csv` - The processed and clean dataset exported from SQLite, ready for BI modeling.
- `README.md` - Project documentation.
